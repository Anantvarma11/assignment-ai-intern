### 8. Scoring Sensitivity & Schema Bug

#### Sensitivity Proof
When simulation quality changes, mutual compatibility drops significantly:
```text
[Baseline Match Score (Date 95)]:  75
[Mutated Match Score (Date 55)]:   54
[Score Delta]: 21 points
```

#### Critical Schema Bug Discovered
In `src/lib/matching/scorer.ts:205`:
```typescript
complementaryBonus: Math.round((secondDateMultiplier - 1) * 50)
```
When `secondDateLikelihood` is `"unlikely"`, `secondDateMultiplier` is set to `0.85`.
Calculation: `(0.85 - 1) * 50 = -7.5 ≈ -8`.
In `src/lib/types/index.ts:177`:
```typescript
complementaryBonus: z.number().min(0).max(10)
```
**Error**: `ZodError: complementaryBonus: Too small: expected number to be >= 0`. Any simulation that evaluates to "unlikely" throws an unhandled crash during score calculation!

### 10. Deployment & Provider Rules Audit

1. **Public Reachability**: App is currently hosted solely on `http://localhost:3000`. No live public Vercel or cloud URL is active.
2. **Key Storage**: Keys are read via server-side process environment (`CEREBRAS_API_KEY`, `OPENROUTER_API_KEY`, `APIFY_TOKEN`) and in-memory runtime overrides (`src/lib/llm/index.ts`). No keys are committed into Git or sent to client bundles.
3. **Fallback Surfacing**:
   - The UI includes a `ProviderBadge` with amber styling for deterministic mode, but does **not** state `FALLBACK` in all caps on dating cards, transcripts, or terminal logs.
   - **Fallback Trigger Rate in Seed Data**: **325 out of 325 dates (100%)** triggered deterministic fallback.

## Action Plan for Phase 2 Implementation

Based strictly on this audit, Phase 2 fixes must address:
1. **Fix Ingestion Pipeline**: Remove silent synthetic fallback. If an unseen URL fails live scraping, return an explicit error state (`422 Unprocessable Profile / Anti-bot Blocked`). If cached snapshot is used, explicitly badge it with `Cached Snapshot from <timestamp>`.
2. **Fix Scorer Zod Bug**: Add `Math.max(0, ...)` to `complementaryBonus` in `scorer.ts` so dates resulting in `"unlikely"` second date do not crash.
3. **Consenting Volunteer Cohort**: Introduce `data/volunteers.csv` with real consenting volunteers.
4. **Real LLM Generation for Dates & Analysis**: Wire Cerebras/OpenRouter into both Analyst and Dating Simulator.
5. **Observability**: Add `/debug` page displaying per-turn prompts, latency, token usage, and explicit "LLM" vs "FALLBACK" badges.
6. **Deploy**: Setup public deployment and produce demo recording.
